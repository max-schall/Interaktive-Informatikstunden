Leitfrage

Wie wird ein Bild im Computer gespeichert?

Station 1 · Pixel

Bilder aus kleinen Punkten

  • Fotos bestehen aus vielen kleinen Bildpunkten, den Pixeln.
  • Pixel sind die kleinsten Einheiten eines digitalen Bildes. Jedes Pixel hat eine eindeutige Farbe und Position.
  • Je mehr Pixel ein Bild enthält, desto höher ist seine Auflösung und desto klarer erscheint es.

Auflösung

Station 2 · Codierung Schwarz-Weiß-Bild

Bilder aus 0 und 1

Bei einem Schwarz-Weiß-Bild sind alle schwarzen Pixel mit 0 codiert, die weißen mit 1. In einer Bilddatei steckt also ein binärer Code. Wird ein Bild in ein Raster aus Pixeln aufgeteilt, spricht man von einer Rastergrafik. Male mit der Maus!

Station 3 · Eigenschaften einer Rastergrafik

Bildgröße und Farbtiefe

  • Die Bildgröße ist die Anzahl der Pixel in Breite und Höhe. Der Smiley hat 8 · 8 Pixel.
  • Die Farbtiefe gibt an, wie viele Bits pro Pixel verwendet werden. Schwarz-Weiß braucht nur 1 Bit (2 Farben).
  • Mehr Bits pro Pixel → mehr Farben → mehr Speicherplatz.

Farbtiefe

Station 4 · Material M2

Dateiformate für Rastergrafiken

Damit ein Computer Rastergrafiken anzeigen kann, werden sie in einem passenden Dateiformat gespeichert. Manche bieten hohe Qualität, andere sparen Speicherplatz.

NameEndungEigenschaften
JPG JPEG – Joint Photographic Experts Group.jpg .jpegspart Speicherplatz, ein Teil der Bildinformationen geht beim Speichern verloren
PNG PNG – Portable Network Graphics.pngfür Bilder mit Linien und Flächen, eher für Logos und Grafiken; durchsichtige Ebenen; Bildinformationen bleiben erhalten
GIF GIF – Graphics Interchange Format.gifkann aus mehreren Einzelbildern bestehen, die als Animation abgespielt werden; Bildinformationen bleiben erhalten
TIFF TIF – Tagged Image File Format.tif .tiffspeichert in hoher Qualität, kein Informationsverlust, benötigt viel Speicherplatz

Hefteintrag: Pixel und Rastergrafiken

Pixel und Rastergrafiken

Informatik · Klasse 5/6
  1. Digitale Bilder bestehen aus Pixeln, den kleinsten Bildpunkten. Jedes Pixel hat eine Farbe und eine Position.
  2. Je mehr Pixel, desto höher die Auflösung und desto klarer das Bild.
  3. Ein Bild aus einem Raster von Pixeln heißt Rastergrafik. Bei Schwarz-Weiß-Bildern: schwarz = 0, weiß = 1.
  4. Bildgröße = Anzahl der Pixel in Breite und Höhe. Farbtiefe = Anzahl der Bits pro Pixel.
  5. Dateiformate: JPEG (spart Platz, mit Verlust), PNG (Logos, durchsichtig, ohne Verlust), GIF (Animationen), TIFF (hohe Qualität, viel Speicher).
