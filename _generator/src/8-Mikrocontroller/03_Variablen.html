Station 1 · Variablen in NEPO

Name, Typ und Wert

  • Eine Variable ist ein Platzhalter – wie in der Mathematik. Ihr Wert kann sich während des Programms ändern.
  • Mit dem + im Startblock wird eine neue Variable angelegt. Man legt Namen, Typ und Anfangswert fest.
  • Im Menü Variablen gibt es für jede Variable eigene Blöcke zum Setzen und Verwenden.

Station 2 · Projekt: Torzähler

Tore zählen auf Knopfdruck

Taste A zählt die Tore von Team A, Taste B die von Team B. Berührt man Pin 1, wird alles auf den Anfangswert 0 zurückgesetzt.

Station 3 · Projekt: Farbmischer

Farben mischen mit drei Variablen

Rot, Grün und Blau werden in drei Variablen gespeichert und starten bei 255 (weiß). Taste A verringert Rot um 51, Taste B verringert Grün, Pin 0 verringert Blau. Unter 0 springt der Wert zurück auf 255.

Hefteintrag: Variablen

Mit Variablen arbeiten

Informatik · Klasse 8
  1. Eine Variable ist ein Platzhalter mit Namen, Typ und Wert. Der Wert kann sich während des Programms ändern.
  2. Typen in NEPO: Zahl, Zeichenkette (Text), logischer Wert (wahr/falsch), Farbe.
  3. Zum Zählen wird eine Variable auf einen Startwert gesetzt und dann immer wieder um 1 erhöht („ändere … um 1“).
  4. Variablen können Farbwerte (RGB 0–255), Messwerte oder Spielstände speichern.
