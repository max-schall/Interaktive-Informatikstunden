Ziele von Datenbanken

Die Daten sollen eindeutig und klar kategorisiert sein, widerspruchsfrei (konsistent) und ohne Redundanzen. Beim Eingeben, Löschen oder Überschreiben dürfen keine Fehler entstehen.

Station 3 · Relationale Datenbanken

Tabellen in Beziehung

In einer relationalen Datenbank liegen die Daten in Tabellen, die zueinander in Beziehung (Relation) stehen. Jeder Datensatz bekommt eine eindeutige Nummer, den Primärschlüssel (ID). Steht diese Nummer in einer anderen Tabelle, heißt sie dort Fremdschlüssel. Tippe eine Zeile der Tabelle Ausleihe an.

  • Datenfeld (Attribut): eine Spalte, z. B. F_Titel
  • Datensatz (Tupel): eine Zeile mit allen Infos zu einem Objekt
  • Attributwert: ein einzelner Eintrag, z. B. „Drama“
  • Primärschlüssel: eindeutige ID, für Nutzer meist unsichtbar
  • Fremdschlüssel: verweist auf den Primärschlüssel einer anderen Tabelle
