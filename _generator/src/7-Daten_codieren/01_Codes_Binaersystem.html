Station 1 · Daten und ihre Codierung

Ein Code ist eine Übersetzungsvorschrift

Beim Codieren wird jedes Zeichen nach einer festen Vorschrift in ein anderes Zeichen oder Symbol umgewandelt – so, dass bestimmte Personen oder Maschinen es verstehen. Die Codierung erfüllt also einen Zweck.

Morsecode

Samuel Morse, 1837

Kurzes Signal = Punkt, langes Signal = Strich. Elektrische Impulse über eine Leitung machten Nachrichten in Minuten möglich.

Brailleschrift

Louis Braille, 1825

Jeder Buchstabe besteht aus bis zu 6 Punkten in einem Rechteck. Die erhabenen Punkte werden ertastet.

Station 2 · Das Binärsystem

Nur zwei Ziffern

  • Im Dezimalsystem gibt es 10 Ziffern (0–9) und die Stellenwerte 1, 10, 100, 1000 …
  • Computer arbeiten nur mit 0 (aus) und 1 (an) – einem Bit. Im Binärsystem (Dualsystem) haben die Stellen die Werte 1, 2, 4, 8, 16, 32, 64, 128 …
  • Eine Dualzahl erkennt man an der tiefgestellten 2: 11100₂, gesprochen „Eins Eins Eins Null Null im Dualsystem“.
  • Dual → dezimal: Jede Ziffer mit ihrem Stellenwert multiplizieren und addieren: 1·16 + 1·8 + 1·4 + 0·2 + 0·1 = 28.

Station 3 · Umrechnen ins Binärsystem

Das Divisionsverfahren

  1. Teile die Dezimalzahl durch 2 und schreibe den Rest (0 oder 1) auf.
  2. Teile das Ergebnis wieder durch 2 – so lange, bis 0 herauskommt.
  3. Lies die Reste von unten nach oben: Das ist die Dualzahl.

Mit 8 Bit (1 Byte) lassen sich die Zahlen 0 bis 255 darstellen.

Zahlen mit Leuchtdioden

Eine Reihe aus 7 LEDs zeigt Zahlen im Binärsystem. Eine leuchtende LED bedeutet 1. Schalte die LEDs für die gesuchte Zahl.

Welche LEDs müssen für 40, 33 und 17 leuchten? Begründe.

Größte Zahl

Welche ist die größte Zahl, die 7 LEDs darstellen können? Und 8 LEDs?

7 LEDs: 1111111₂ = 127 (also 128 verschiedene Zahlen 0–127). 8 LEDs: 11111111₂ = 255 (256 Zahlen).

Hefteintrag: Codes und Binärsystem

Codes und das Binärsystem

Informatik · Klasse 7
  1. Ein Code ist eine Vorschrift, nach der Zeichen in andere Zeichen übersetzt werden (z. B. Morsecode, Brailleschrift, Barcode). Codierung erfüllt einen Zweck.
  2. Computer arbeiten im Binärsystem mit den Ziffern 0 und 1. Die Stellenwerte sind Zweierpotenzen: 1, 2, 4, 8, 16, 32, 64, 128.
  3. Dual → dezimal: Ziffern mit Stellenwerten multiplizieren und addieren: 11100₂ = 16 + 8 + 4 = 28.
  4. Dezimal → dual: immer wieder durch 2 teilen, die Reste von unten nach oben lesen: 28 = 11100₂.
