Station 1 · Datenfelder in JavaScript

Viele Werte, ein Name

  • Ein Datenfeld (Array) wird mit eckigen Klammern angelegt: var A = [4, 8, 15, 16];
  • Jedes Element hat einen Index. Achtung: Er beginnt bei 0! A[0] ist 4, A[3] ist 16.
  • A.length ist die Länge (hier 4), A.push(23) hängt ein Element an.
  • A[1] = 9; weist einem Element einen neuen Wert zu.

Station 3 · Werte tauschen

Ohne Hilfsvariable geht es schief

Ein wichtiges Konzept (z. B. beim Sortieren): die Werte zweier Elemente tauschen. Schreibt man einfach A[0] = A[1]; A[1] = A[0];, ist der alte Wert von A[0] verloren. Man braucht eine Hilfsvariable – wie beim Tauschen zweier voller Gläser ein drittes, leeres Glas.

Station 4 · Methode: Fehlersuche

Wo steckt der Bug?

Softwarefehler heißen Bugs (Käfer). Syntaktische Fehler verletzen die Regeln der Sprache (Klammern, Semikolons). Semantische Fehler: Der Code läuft, tut aber nicht, was er soll. Strategien: Fehlermeldung lesen, Werte mit Console.print ausgeben, Code Schritt für Schritt durchgehen, Debugger mit Haltepunkten nutzen. Welche Fehler stecken im Code?

1. var summe; hat keinen Startwert (undefined). undefined + 3 ergibt NaN („keine Zahl“) – ein semantischer Fehler. Richtig: var summe = 0;
2. Die Bedingung i <= A.length läuft einen Schritt zu weit: A[5] gibt es nicht. Richtig: i < A.length.

Hefteintrag: Datenfelder

Datenfelder und Fehlersuche

Informatik · Klasse 8
  1. Ein Datenfeld speichert eine Liste von Werten: var A = [4, 8, 15];. Zugriff über den Index, der bei 0 beginnt: A[0].
  2. A.length = Anzahl der Elemente, A.push(x) hängt x an. Mit einer for-Schleife von 0 bis A.length − 1 durchläuft man alle Elemente.
  3. Zum Tauschen zweier Werte braucht man eine Hilfsvariable: h = A[0]; A[0] = A[1]; A[1] = h;
  4. Fehlerarten: syntaktisch (Regeln verletzt) und semantisch (falsches Verhalten). Strategien: Fehlermeldung lesen, Werte ausgeben, Schritt für Schritt prüfen, Debugger.
