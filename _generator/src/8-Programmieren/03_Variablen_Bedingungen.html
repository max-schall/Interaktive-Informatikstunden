Station 1 · Variablen in JavaScript

Behälter für Daten

  • Variablen sind wie Schubladen eines Apothekerschranks – nur mit Daten gefüllt.
  • Mit dem Schlüsselwort var wird eine Variable deklariert und meist gleich initialisiert: var x = 5;
  • Der Name beginnt mit einem Buchstaben und darf Buchstaben, Ziffern und _ enthalten.
  • Datentypen: Zahl (3.5) und Zeichenkette ("rot"). Mit Zahlen rechnet man mit + − * /; % liefert den Rest.
  • x = x + 1; heißt: Nimm den alten Wert, addiere 1, speichere das Ergebnis wieder in x.

Station 3 · Bedingte Anweisungen

if und else

  • Eine Bedingung ist ein Vergleich, der wahr oder falsch ergibt. Vergleichsoperatoren: < > <= >= == !=.
  • if (Bedingung) { … } führt den Block nur aus, wenn die Bedingung wahr ist.
  • if … else führt sonst den else-Block aus.
  • && (und): beide Vergleiche müssen wahr sein. || (oder): mindestens einer muss wahr sein.

Variablen und bedingte Anweisungen

Informatik · Klasse 8
  1. var name = wert; deklariert und initialisiert eine Variable. Datentypen: Zahl, Zeichenkette.
  2. Zuweisung x = x + 1;: rechte Seite berechnen, Ergebnis in x speichern. % berechnet den Rest einer Division.
  3. Vergleichsoperatoren < > <= >= == != liefern wahr oder falsch.
  4. if (…) { … } else { … }; Verknüpfung mit && (und) und || (oder).
