Station 1 · Textbasierte Programmierung

Dasselbe Programm – zwei Sprachen

Bei einer grafischen Programmiersprache (Scratch, NEPO) werden Befehle als Blöcke dargestellt. Bei einer textbasierten Sprache wird der Ablauf als lesbarer Text aus Zeichen, Symbolen und Schlüsselwörtern geschrieben: dem Quellcode. Ein Compiler oder eine Laufzeitumgebung (hier der Browser) macht ihn für den Computer verständlich.

Station 2 · Syntax

Regeln für den Text

  • Jede Anweisung endet mit einem Semikolon ;.
  • Zeilen, die mit // beginnen, sind Kommentare. Sie erklären den Code und werden nicht ausgeführt.
  • Zeichenketten (Text) stehen in Anführungszeichen: "Hallo".
  • Groß- und Kleinschreibung zählt: Canvas ≠ canvas.
  • Klammern kommen immer paarweise: ( ), { }, [ ].

Station 3 · Die Canvas-Zeichenfläche

Zeichnen mit Befehlen

Canvas.init([0,20], [0,12], {background:"lightgrey"}) legt eine Zeichenfläche an: x von 0 bis 20, y von 0 bis 12. Der Ursprung liegt unten links. Canvas.circle(10, 6, 5, {fill:"blue"}) zeichnet einen Kreis mit Mittelpunkt (10 | 6) und Radius 5. Ändere den Code und klicke auf „Ausführen“!

Station 4 · Argumente und Optionen

Was muss, was kann?

  • Verpflichtende Argumente stehen der Reihe nach in runden Klammern: Position und Größe.
  • Optionale Parameter stehen in geschweiften Klammern mit Namen und Doppelpunkt: {fill:"red"}. Fehlen sie, gilt ein Standardwert (schwarz).
  • Kommazahlen schreibt man mit Punkt: 2.5.
  • Farben als Name ("red", "gold") oder als RGB: "rgb(255,128,0)".
Befehle

Canvas.circle(x, y, r, {fill})
Canvas.rect(x, y, breite, höhe, {fill})
Canvas.line(x1, y1, x2, y2, {stroke, width})
Canvas.text(x, y, "Text", {fill, size})
