Station 1 · Die for-Schleife

Drei Angaben in einer Klammer

  • Die for-Schleife (Zählschleife) beginnt mit dem Schlüsselwort for.
  • In den runden Klammern stehen: Initialisierung der Zählvariablen, Schleifenbedingung und Zählschritt.
  • Die Anweisungen in { } werden ausgeführt, solange die Bedingung erfüllt ist. Nach jedem Durchlauf wird die Zählvariable verändert.

Station 2 · Muster mit Schleifen

Eine Reihe von Kreisen

Die Zählvariable x bestimmt die Position. Ändere Startwert, Bedingung und Schritt. Mit random(a, b) entstehen Zufallsmuster – probiere die Beispiele.

Station 3 · Verschachtelte for-Schleifen

Ein Raster aus zwei Schleifen

Die äußere Schleife bestimmt die y-Koordinaten (Zeilen), die innere die x-Koordinaten (Spalten). Bei jedem Durchlauf der äußeren läuft die innere komplett. Mit einer Bedingung entsteht ein Schachbrett.

Schleifen in JavaScript

Informatik · Klasse 8
  1. for (var i = 0; i < 10; i = i + 1) { … } – Initialisierung, Bedingung, Zählschritt.
  2. Ablauf: Zählvariable initialisieren → Bedingung prüfen → wenn wahr: Anweisungen ausführen → Zählschritt → wieder prüfen … bis die Bedingung falsch ist.
  3. Die Zählvariable kann im Block genutzt werden, z. B. als Koordinate: Canvas.circle(x, 6, 0.4).
  4. Verschachtelte Schleifen: äußere Schleife für die Zeilen, innere für die Spalten – so entstehen Raster.
