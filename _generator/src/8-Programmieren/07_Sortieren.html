Leitfrage

Wie sortiert ein Computer ein Datenfeld – und welches Verfahren ist schneller?

Station 1 · Von Hand sortieren

Tausche zwei Nachbarn

Sortiere die Zahlen aufsteigend. Du darfst nur zwei benachbarte Karten tauschen: Tippe auf die Lücke zwischen ihnen. Wie viele Tauschvorgänge brauchst du?

Station 2 · Bubblesort

Große Werte steigen auf wie Blasen

  • Zwei benachbarte Elemente werden verglichen. Ist das linke größer, werden sie getauscht.
  • Nach einem Durchlauf steht das größte Element ganz rechts – es ist „aufgestiegen“ wie eine Blase.
  • Das wird wiederholt, bis keine Vertauschung mehr nötig ist.
  • Leicht zu verstehen, aber bei großen Datenfeldern langsam.

Station 3 · Selectionsort

Das Kleinste nach vorn

  • Suche im unsortierten Teil das kleinste Element.
  • Tausche es an die erste Stelle des unsortierten Teils.
  • Der sortierte Teil wächst von links um ein Element. Wiederhole, bis alles sortiert ist.
  • Es braucht ähnlich viele Vergleiche wie Bubblesort, aber deutlich weniger Vertauschungen.

Station 4 · Aufwand

Doppelt so lang – viermal so viel Arbeit

Bei n Elementen braucht Bubblesort im schlimmsten Fall etwa n · n / 2 Vergleiche. Verdoppelt man die Länge, vervierfacht sich der Aufwand. Deshalb werden in der Praxis schnellere Verfahren genutzt (z. B. Quicksort, Mergesort).

Hefteintrag: Sortieren

Sortierverfahren

Informatik · Klasse 8
  1. Ein Sortierverfahren ist ein Algorithmus, der ein Datenfeld ordnet (z. B. aufsteigend).
  2. Bubblesort: benachbarte Elemente vergleichen und tauschen, wenn das linke größer ist. Nach jedem Durchlauf steht das größte Element am Ende.
  3. Selectionsort: das kleinste Element des unsortierten Teils suchen und an dessen Anfang tauschen.
  4. Der Aufwand wächst stark: doppelte Länge → etwa vierfache Zahl an Vergleichen. Für große Datenmengen nutzt man schnellere Verfahren.
