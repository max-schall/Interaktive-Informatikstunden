Leitfrage

Wie definiert man eigene Befehle und Funktionen?

Station 1 · Befehle definieren

Ein Befehl für Smileys

Mit dem Schlüsselwort function, einem eindeutigen Namen und Argumenten in runden Klammern wird ein Befehl definiert. Die Anweisungen stehen in geschweiften Klammern. Aufgerufen wird er mit Namen und Werten: smiley(5, 6). Ergänze ein drittes Argument für die Farbe!

Station 2 · Funktionen

Funktionen geben etwas zurück

  • Eine Funktion berechnet einen Wert in Abhängigkeit von Argumenten und gibt ihn mit return zurück.
  • Der Rückgabewert kann in einer Variablen gespeichert oder direkt weiterverwendet werden: var a = flaeche(3, 4);
  • JavaScript bringt das Math-Paket mit: Math.sqrt (Wurzel), Math.round (runden), Math.sin, Math.PI …

Station 3 · Methode: Unterprogramme und Anforderungen

Erst beschreiben, dann programmieren, dann testen

Befehle und Funktionen sind Unterprogramme. Zuerst werden Anforderungen festgelegt: Was soll es leisten, welche Argumente gibt es, was kommt heraus? Dann wird implementiert – und mit Testfällen geprüft. Ein Beispiel, wie wichtig das ist: 1996 zerstörte sich die Rakete Ariane 5 40 Sekunden nach dem Start, weil ein Unterprogramm aus der Vorgängerrakete nicht ausreichend für die neuen Werte getestet worden war.

Anforderung

Die Funktion note(punkte) bekommt die Punkte einer Arbeit (0–50) und gibt die Note zurück: ab 45 → 1, ab 38 → 2, ab 30 → 3, ab 22 → 4, ab 12 → 5, sonst 6. Bei Werten außerhalb 0–50 gibt sie −1 zurück.

Aufgabe: Führe die Tests aus. Ein Test schlägt fehl – finde den Fehler in der Implementierung und behebe ihn.

Grenzfall 12 Punkte: Die Bedingung punkte > 12 muss punkte >= 12 heißen, denn laut Anforderung gibt es ab 12 Punkten die Note 5.

Hefteintrag: Funktionen

Befehle und Funktionen

Informatik · Klasse 8
  1. Ein Befehl wird mit function name(arg1, arg2) { … } definiert und mit name(wert1, wert2); aufgerufen.
  2. Eine Funktion gibt mit return einen Wert zurück, der weiterverwendet werden kann.
  3. Befehle und Funktionen vermeiden Wiederholungen und machen Programme übersichtlich. Das Math-Paket liefert fertige Funktionen.
  4. Unterprogramme entwickelt man in drei Schritten: Anforderungen definieren → implementieren → testen.
