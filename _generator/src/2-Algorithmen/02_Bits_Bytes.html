Kleinste Speicherkapazität

Die kleinste Informationseinheit ist das Bit: „1“ = An/Wahr, „0“ = Aus/Falsch. Weil Computer auf elektronischen Schaltungen beruhen, können sie nur mit „Strom an“ und „Strom aus“ codieren.

Bitfolge

Für Zahlen oder Buchstaben werden mehrere Bits zu einer Bitfolge zusammengefasst. Bilder, Musik und Videos brauchen je nach Größe unterschiedlich viel Speicherplatz.

Station 2 · Bytes

8 Bit = 1 Byte

  • Mit nur zwei Zeichen sind die Möglichkeiten begrenzt. Deshalb fasst man 8 Bits zu einem Paket zusammen: einem Byte (B).
  • Mit 8 Stellen aus 0 und 1 gibt es 2⁸ = 256 verschiedene Kombinationen.
  • Der Buchstabe A wird zum Beispiel als 01000001 codiert.
01100110

Beschreibe den Unterschied zwischen Bits und Bytes.

Station 4 · Daten übertragen

Bit pro Sekunde

Speichergrößen von Festplatten werden in Bytes angegeben. Datenübertragungen werden in Bits pro Sekunde angegeben.
  • Internetanbieter werben mit z. B. 100 Mbit/s – das sind 100 000 kbit pro Sekunde oder 100 Millionen Bit pro Sekunde.
  • Achtung: 1 Byte = 8 Bit. Mit 100 Mbit/s lädt man pro Sekunde also 12,5 MB.

Hefteintrag: Bits und Bytes

Bits und Bytes

Informatik · Klasse 5/6
  1. Daten werden im Computer als Binärcode aus 0 und 1 gespeichert.
  2. Das Bit ist die kleinste Informationseinheit: 1 (an) oder 0 (aus).
  3. 8 Bit = 1 Byte. Mit einem Byte gibt es 2⁸ = 256 Kombinationen, z. B. A = 01000001.
  4. Speichereinheiten: 1 KB = 1000 B, 1 MB = 1000 KB, 1 GB = 1000 MB, 1 TB = 1000 GB (früher 1024).
  5. Speichergrößen gibt man in Bytes an, Übertragungsgeschwindigkeiten in Bit pro Sekunde (z. B. 50 Mbit/s).
Skizze

Zeichne die Einheiten-Treppe: Bit → (·8) Byte → (·1000) KB → MB → GB → TB.
