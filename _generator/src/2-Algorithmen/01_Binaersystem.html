Station 2 · Binärsystem

Nur 0 und 1

  • Wir nutzen das Dezimalsystem (10er-System) mit den Ziffern 0 bis 9.
  • Ein Computer arbeitet nur mit 0 und 1: Der Code heißt Binary Digit, kurz Bit. „0“ bedeutet „Aus“, „1“ bedeutet „An“.
  • In einer Stellenwerttafel haben die Stellen im Dezimalsystem die Werte 1, 10, 100, 1000 … (immer ·10).
  • Im Binärsystem heißen die Stellenwerte 1, 2, 4, 8, 16 … (immer ·2).
  • Binärzahlen heißen auch Dualzahlen. Man kennzeichnet sie mit einer tiefgestellten 2: 11100₂.

Station 3 · Umrechnung

Umrechnen in beide Richtungen

Dualzahl → Dezimalzahl

Jede Ziffer mit ihrem Stellenwert multiplizieren, dann alles addieren:

11100₂ = 1·16 + 1·8 + 1·4 + 0·2 + 0·1 = 28

A

Probier's

Rechne die Binärzahl 1111₂ in eine Dezimalzahl um.

1111₂ = 1·8 + 1·4 + 1·2 + 1·1 = 15

Dezimalzahl → Dualzahl

Die Zahl immer wieder durch 2 teilen. Die Reste von unten nach oben gelesen ergeben die Dualzahl.

Merke: Mit 8 Bits (1 Byte) lassen sich die Dezimalzahlen 0 bis 255 darstellen.

Hefteintrag: Das Binärsystem

Das Binärsystem

Informatik · Klasse 5/6
  1. Computer arbeiten nur mit den Ziffern 0 (Aus) und 1 (An). Eine solche Stelle heißt Bit (Binary Digit).
  2. Im Binärsystem (Dualsystem) haben die Stellen die Werte 1, 2, 4, 8, 16, 32, 64, 128 … Dualzahlen schreibt man z. B. als 11100₂.
  3. Dual → Dezimal: Ziffer mal Stellenwert, dann addieren: 11100₂ = 16 + 8 + 4 = 28.
  4. Dezimal → Dual: immer durch 2 teilen, die Reste von unten nach oben lesen: 28 → 11100₂.
  5. Mit 8 Bits (1 Byte) kann man die Zahlen 0 bis 255 darstellen.
