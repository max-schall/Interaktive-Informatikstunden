Wie funktioniert eine Cloud – und sollte man ihr seine Daten anvertrauen?

Station 1 · Aufbau einer Cloud

Keine Wolke, sondern Server

  • Eine Cloud ist ein Netz miteinander verbundener Server. In Serverfarmen sind sehr viele Server zusammengeschaltet – sie brauchen viel Strom.
  • Telekommunikationsfirmen stellen die Verbindung zwischen Nutzern und Cloud-Anbietern her.
  • Private Nutzer greifen mit Computer, Handy oder Tablet auf ihre Daten zu und synchronisieren sie.
  • Unternehmen mieten Speicher nach Bedarf und sparen eigene Server und Räume.

Vorteil oder Nachteil? Sortiere.

1

Stellung nehmen

Alina sagt: „Ich habe nichts zu verbergen.“ Nimm Stellung.

Auch wer „nichts zu verbergen“ hat, hat private Fotos, Adressen, Nachrichten und Passwörter. Gelangen sie in fremde Hände, können sie missbraucht werden (Erpressung, Identitätsdiebstahl, Werbung). Viele Anbieter sitzen außerhalb der EU, wo die strengen europäischen Datenschutzregeln nicht gelten. Wichtig sind ein sicheres Passwort, Zwei-Faktor-Anmeldung und ein vertrauenswürdiger Anbieter.

Hefteintrag: Die Cloud

Die Cloud

Informatik · Klasse 7
  1. Eine Cloud ist ein Netz verbundener Server in Serverfarmen, auf die man über das Internet zugreift.
  2. Daten (Musik, Fotos, Dokumente) liegen auf dem Server. Mehrere Geräte können darauf zugreifen und werden synchronisiert.
  3. Vorteile: Zugriff von überall, Schutz vor Datenverlust bei defektem Gerät, gemeinsames Bearbeiten, kein eigener Speicher nötig.
  4. Nachteile: Internetverbindung nötig, Datenschutz (Anbieter oft außerhalb der EU), Gefahr durch Hacker – deshalb sicheres Passwort; hoher Stromverbrauch.
